# 📸 Preview - SpedRevio Dashboard

## 🎨 Interface Moderna e Elegante

O SpedRevio Dashboard apresenta uma interface completamente redesenhada, inspirada no site da Revio, com foco em modernidade, usabilidade e experiência do usuário.

## 🌟 Principais Características Visuais

### 1. **Header Moderno**
- Logo SpedRevio com gradiente azul
- Fundo semi-transparente com efeito blur
- Menu de usuário com avatar
- Design sticky que acompanha o scroll

### 2. **Sidebar Elegante**
- Cards de navegação com ícones coloridos
- Estado ativo com gradiente azul
- Efeitos hover suaves
- Card de dica informativa no rodapé

### 3. **Dashboard**
- 4 cards de estatísticas com ícones em gradiente
- Gráficos de performance com barras de progresso
- Cards de resumo financeiro coloridos
- Layout responsivo em grid

### 4. **Listagem de Notas**
- Cards modernos com informações organizadas
- Ícones contextuais para cada seção
- Status com badges coloridos
- Hover effect com scale

### 5. **Grid Completa (TanStack Table)**
- Tabela profissional com ordenação
- Filtros avançados em card destacado
- Paginação completa
- Busca rápida integrada

### 6. **Detalhes da Nota**
- Header com ícone e informações principais
- Cards coloridos para emitente/destinatário
- Tabela de itens com header em gradiente
- Chave de acesso em destaque

## 🎨 Paleta de Cores

### Azul Revio (Principal)
```
Primary: #1e40af
Secondary: #3b82f6
Accent: #60a5fa
Light: #dbeafe
```

### Gradientes
```
Primário: linear-gradient(to right, #1e40af, #3b82f6)
Fundo: linear-gradient(135deg, #f0f9ff, #e0f2fe)
```

## ✨ Efeitos e Animações

- **Hover**: Scale, translate, shadow
- **Loading**: Spinner duplo animado
- **Transições**: 200ms ease-in-out
- **Cards**: Elevação suave no hover

## 📱 Responsividade

### Mobile
- Menu hambúrguer
- Cards empilhados
- Sidebar colapsável

### Tablet
- Layout híbrido
- Grid de 2 colunas

### Desktop
- Layout completo
- Grid de 4 colunas
- Sidebar fixa

## 🎯 Componentes Destacados

### Botões
- **Primário**: Gradiente azul com sombra
- **Secundário**: Borda azul com hover

### Cards
- Fundo branco
- Sombra personalizada (shadow-revio)
- Bordas arredondadas (12px)

### Inputs
- Borda dupla
- Focus ring azul
- Ícones integrados

### Status Badges
- **Autorizada**: Verde
- **Cancelada**: Vermelho
- **Processando**: Amarelo
- **Denegada**: Laranja

## 🏆 Diferenciais

1. **Design System Completo**: Baseado no Tailwind CSS com customizações
2. **Identidade Visual Revio**: Cores e estilo alinhados com a marca
3. **UX Moderna**: Feedback visual em todas as interações
4. **Performance**: Animações otimizadas e carregamento rápido
5. **Acessibilidade**: Contraste adequado e navegação por teclado

## 🎨 Inspiração

O design foi inspirado no site oficial da Revio (https://revio.global), mantendo:
- Paleta de cores azul profissional
- Gradientes suaves
- Espaçamento generoso
- Tipografia clara e legível
- Elementos modernos e minimalistas
