┌──────────────────────────────────────────────────────────────────────────────┐
│  PROBLEMAS COMUNS                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  ❌ "Servidor de Agregação Não Disponível"
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ Causa: Servidor MongoDB não está rodando                                  │
  │                                                                            │
  │ Solução:                                                                   │
  │   npm run aggregation                                                      │
  │                                                                            │
  │ Ou use o atalho:                                                           │
  │   iniciar-completo.bat                                                     │
  └────────────────────────────────────────────────────────────────────────────┘

  ❌ Gráficos não aparecem
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ Causa: Sem dados no período selecionado                                   │
  │                                                                            │
  │ Solução:                                                                   │
  │   1. Mude o período (ex: últimos 90 dias)                                 │
  │   2. Verifique se há dados no banco                                       │
  │   3. Abra o console do navegador (F12) para ver erros                     │
  └────────────────────────────────────────────────────────────────────────────┘

  ❌ ECONNREFUSED ou ERR_NETWORK
  ┌────────────────────────────────────────────────────────────────────────────┐
  │ Causa: Porta 3002 ocupada ou servidor não iniciou                         │
  │                                                                            │
  │ Solução:                                                                   │
  │   1. Feche outros processos na porta 3002                                 │
  │   2. Reinicie o servidor: npm run aggregation                             │
  │   3. Verifique logs do terminal                                           │
  └────────────────────────────────────────────────────────────────────────────┘
