# 🎯 Apresentação - SpedRevio Dashboard

## 👋 Olá!

Apresentamos o **SpedRevio Dashboard**, um sistema completo e moderno para gerenciamento de notas fiscais eletrônicas.

## 🌟 O Que É?

O SpedRevio Dashboard é uma aplicação web desenvolvida com as melhores tecnologias do mercado, oferecendo uma interface elegante e intuitiva para consulta e análise de notas fiscais eletrônicas (NF-e).

## 🎨 Design Inspirado na Revio

## 🚀 Como Começar

### 1. Instalar
```bash
npm install
```

### 2. Configurar
```bash
copy .env.example .env
# Edite o .env com suas credenciais
```

### 3. Executar
```bash
npm run dev
```

### 4. Acessar
```
http://localhost:5173
```
